# Hero.X Portfolio OS

> An interactive portfolio website styled as a retro Windows XP + cyberpunk operating system.

## Features

- 🖥️ Full fake OS desktop experience
- 🚀 Cinematic boot sequence (BIOS → loading → login)
- 🪟 Draggable, resizable, minimizable windows
- 💻 Functional terminal with 15+ commands
- 🎵 Retro music player with equalizer
- 🌐 IE-style socials browser
- 📧 XP Outlook-style contact form
- 💬 Messenger-style reviews chat
- 🔒 Password-protected secret files
- 🎮 Easter eggs (Konami code, matrix mode, BSOD)
- ✨ Framer Motion animations throughout
- 📱 Mobile responsive

## Tech Stack

- **Next.js 15** + TypeScript
- **Tailwind CSS** + custom animations
- **Framer Motion** for all animations
- **Lucide React** + React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

- Konami Code: ↑↑↓↓←→←→BA
